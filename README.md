# MaxOS

MaxOS is my own build of Android 16 for the LG V60 ThinQ 5G (timelm). It is a
GSI built on the crDroid 16.2 + TrebleDroid base, with my own fixes and
branding baked in at compile time instead of toggled by hand after every flash.

Why it exists: stock LG software is full of bloat and stopped receiving
updates, and generic GSIs leave the V60's quirks unfixed. This build fixes
them in the source tree.

## What is fixed compared to a generic GSI

- Headphone jack detection (kernel switch events were fine, the framework was
  listening on the wrong path - now wired correctly by default)
- All camera devices exposed (main, ultrawide, selfie, aux)
- The dedicated Assistant button remapped from KEY_TV to ASSIST
- Qualcomm audio policy defaults set for this device
- Real camera video profiles to replace the generic ones (4K60/8K24 work in
  progress)
- Vibration, double-tap-to-wake and cutout fixes (in progress)

## What it is not

- It is not ColorOS. It is not affiliated with OPPO, OnePlus, LG, Google,
  LineageOS or the crDroid team. It is a personal build for my own phone.

## Build

Built on GitHub Actions, see .github/workflows/build.yml. The boot animation
and branding assets are generated by branding/gen_branding.py, no hand-drawn
frames involved.
